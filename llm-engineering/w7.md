# Fine-Tuned Open-Source Model To Compete With Frontier Model

## High level explanation of LoRA (Low Ranking Adapter)

Using Llamam 3.2 with 3B weights - far too much for us to train on a GPU

- Llama 3.2 3B architecture consists of 28 groups of modules stacked on top of each other, called "Llama Decoder Layers"
- Each has self-attention layers, multi-layer perceptron layers, SiLU activation and layer norm
- These parameters take up 13GB memory

**Step-1**: Freeze the weights - we will no optimize them

**Step-2**: Select some layers to target, called "Target Modules"

**Step-3**: Create new "adaptor" matrices with lower dimensions, fewer parameters (Low Rank Adaptor)

**Step-4**: Apply these adaptors to the Target Modules to adjust them - and these get trained
        To be more precise: there are in fact two LoRA matrices that get applied


## Three Essential Hyperparameters For LoRA Fine-Tuning

**r** : The rank, or how many dimensions in the low-rank matrices
    RULE OF THUMB: Start with 8, then double to 16, then 32, until diminishing returns

**Alpha**: A scaling factor that multiplies the lower rank matrices
    RULE OF THUMB: Twice the value of r

**Target Modules**: Which layers of the neural network are adapted
    RULE OF THUMB: Start by targeting the attention heads

## Quantization  - the Q in QLoRA

Even the 3B variants are enormous

- 3 Billion * 32 bits = 13GB
- Intuition: Keep the number of weights but reduce their precision
- Model performance is worse, but the impact is surprisingly small
- Reduce to 8 bits, or even to 4 bits
  - Note-1: 4 bits are interpreted as float, not int
  - Note-2: the adaptor matrices are still 32 bits
