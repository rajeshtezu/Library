## Intro to Tokenizer

- It maps between Text and Tokens for a particular model.

Two steps:
1. breaks down the sentences into words (tokens)
2. convert word (token) into number (token id)

- Contains a vocab that can include special tokens to signal information to the LLM, like start of prompt.

Different LLMs have own Tokenizer:

e.g.
Llama 3.1 --> Meta
Phi 4 --> Microsoft
DeepSeek 3.1 --> DeepSeek AI
Qwen 2.5 Coder --> Leading open-source coding model
