# ML to DL to Fine-Tuning a Frontier Model

- Training is the core idea of AI
- It involves setting the parameters of a model based on the inputs and outputs
- AFter training, the model is given a new inputs ("Unseen data")

The ability of a model to make good predictions on unseen data is called "Generalization".

LLMs are remarkably good at generalization.


- Training a multi-billion parameter model from scratch would cost tens to hundreds of million dollar
- Instead, we take advantage of Transfer Learning
- We take a pre-trained model as base, and use additional training data to fine-tune it for our task

## Divide Data

Data is typically divided into 3 datasets
1. **Training Data**: The majority of data used to learn patterns to make new predictions
2. **Validation Data**: Held-out data used to evaluate whether the model can make new predictions accurately
3. **Test Data**: Held-out data used at the end of the process to confirm model prediction accuracy

## Machine Learning

- A branch of AI where algorithm learn from data to make predictions without being explicitly programmed.
- These days, ML is most often used in the context of traditional ML, pre-Deep Learning & LLMs
- It's still crucial to understand core ML principles to be an LLM practitioner

- Generalizing: The ability to perform well on new, unseen data by capturing underlying patterns
- Overfitting: When a model mimics the data too closely, leading to poor performance on unseen data
- The goal of Machine Learning is to GENERALIZE - to make accurate predictions on unseen data

## The four steps of Training

Tweaking the parameters of a model based on training data in a way that should generalize to unseen data

1. **Forward pass**: Predict the output given inputs 
2. **Loss calculation**: How different was the prediction to the ground truth
3. **Backward pass**: How should we tweak parameters to do better next time (the "gradients")
4. **Optimization**: Update parameters a tiny step to do better next time

We can specify additional settings that aren't updated during training known as hyper-parameters
Like **epoch** and **learning rate**

- **epoch**: one complete pass of the entire training dataset through a machine learning or deep learning model
- **learning rate**: that controls the size of the step a machine learning model takes during each iteration of optimization

The process of experimenting with these is called **hyper-parameter optimization**.
(It's basically a fancy way of saying Trial & Error)

## Three Stages to Fine-Tuning with OpenAI

The same is generally applicable to other models as well

1. Create Training Dataset in **jsonl** format and upload to OpenAI
2. Run training - training loss and validation loss should decrease
3. Evaluate results, tweak and repeat
