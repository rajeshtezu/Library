## Defining Agents

Old def --> "LLM that controls the workflow" (Not literally)

New def --> "An LLM agent runs tools in a loop to achieve a goal"

Common features:
- Memory / persistence
- Planning capabilities
- Autonomy
- LLM orchestration via Tools
- Functionality via Tools
