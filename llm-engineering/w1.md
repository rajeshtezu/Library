# Build First LLM Product: Exploring Top Models

## ollama

An open source tool to run models locally.

### Install and run free/paid models 
```
ollama run <model>
```

e.g.
```
ollama run phi3
```

Note: Search for the models: https://ollama.com/search

### Help
```
ollama --help
```

## LLM Flavors

Comes in 3 flavors:

1. Base
     - Better for fine-tuning to learn a new skill
2. Chat/Instruct
     - Better for interactive use cases and creative content generation
3. Reasoning/Thinking (budget forcing)
     - Better for problem solving

Hybrid = Chat/Instruct + Reasoning/Thinking

## Tokenizer

https://platform.openai.com/tokenizer

-------------------

- LLM does not have memory, you have to send all of the previous conversation to make sense of the new prompt. So in an ongoing conversation, every new prompt increases the context.


**Context window**:

Max number of tokens that the model can consider when generating the next token.
It governs how well the model can remember references, context and context.

Context windows and API costs: https://www.vellum.ai/llm-leaderboard
